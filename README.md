# Ark Backend

Premium investment broker platform backend.

## Tech Stack

- Node.js + Express
- MongoDB Atlas + Mongoose
- Redis (caching, sessions)
- JWT Authentication
- Cloudinary for file uploads
- MailerSend for emails
- Socket.io for real-time notifications

## Setup

1. Clone repository
2. Copy `.env.example` to `.env` and fill in values
3. Run `npm install`
4. Run `npm run seed` to populate initial data (currencies, investment plans, admin)
5. Run `npm run dev` for development
